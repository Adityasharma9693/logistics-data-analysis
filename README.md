# Logistics Data Analysis & Route Optimization

## Description
This project simulates a strategic data analysis initiative aimed at optimizing last-mile delivery logistics for a regional distribution hub. The primary objective is to address common supply chain challenges—such as unpredictable transit times, inefficient vehicle loading, and overlapping routes—using data science methodologies. 

By leveraging simulated historical order data and telematics, this project demonstrates how to apply unsupervised learning (K-Means clustering) for geographic territory assignment and supervised learning (Random Forest regression) for precise Estimated Time of Arrival (ETA) prediction. 

**Key Objectives:**
* Improve On-Time Delivery Rate (OTDR)
* Reduce operational Cost per Delivery (CpD)
* Maximize Vehicle Capacity Utilization (VCU)

**Tech Stack:** Python, Pandas, Scikit-Learn
